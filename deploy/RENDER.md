# Публикация на Render (бесплатно, один сервис)

Сервер сам отдаёт мобильную страницу и WebSocket на одном порту: одна ссылка
работает и в браузере телефона, и для десктопного клиента.

## Что нужно
- аккаунт GitHub (бесплатно);
- аккаунт Render (бесплатно, вход через GitHub, карта не нужна);
- 5 минут.

## Шаги
1. Залей проект в GitHub:
   ```bash
   cd krug
   git init && git add . && git commit -m "Pakost Chatting"
   git branch -M main
   git remote add origin git@github.com:ТВОЙ_НИК/pakost-chatting.git
   git push -u origin main
   ```
2. Открой https://dashboard.render.com → **New** → **Blueprint** → выбери репозиторий.
3. Render найдёт `render.yaml`. В поле `KRUG_INVITE` впиши код для друзей,
   например `svoi-2026`. Нажми **Apply**.
4. Дождись сборки (5–10 минут). Получишь адрес вида
   `https://pakost-chatting.onrender.com`.
5. Открой его на телефоне — это и есть приложение. Вход: имя, пароль,
   инвайт. Десктопный клиент подключай к `wss://pakost-chatting.onrender.com`.

## Ограничения бесплатного тарифа
- сервис засыпает через 15 минут без запросов: первое открытие до минуты;
- диск временный: после перезапуска история и аккаунты обнуляются;
- 750 часов в месяц — вечерних игр хватает с запасом.
